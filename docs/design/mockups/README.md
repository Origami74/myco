# UI mockups — historical

Seven SVG mockups drawn before the consumer UI existed (the P3.5 pass). They
are kept for the record; the shipped screens moved on:

- The shell is a bottom-nav with **Apps · Circle · Discover · Settings · Dev**;
  mockup 03 predates the Circle tab's bump-to-pair and file sharing.
- The Apps grid holds **napplets** as well as nsites (🦆 badge), and the
  long-press sheet (mockup 02) gained **Manage permissions** and **Reload app**.
- Settings (04) gained Mesh lanes (Bluetooth, Wi-Fi Aware, Network), **App
  reach**, Storage with custom relay/Blossom, and Identity.
- The QR flow (06) is now one of two: NFC bump is the headline.
- "Getting an app" (07) has a napplet variant: the install review sheet.

For what the screens look like today, run the app or see the screenshots in
[`docs/images/`](../../images/). Redraw these when a UI pass is planned, not
before.
