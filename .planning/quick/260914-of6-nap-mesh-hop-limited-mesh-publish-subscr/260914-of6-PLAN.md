# NAP-MESH: hop-limited mesh publish/subscribe for napplets

A new capability domain `mesh`, specified in NAP-WORD template form so it can
be proposed upstream (napplet/naps), and implemented behind the runtime's
seams. Distinct from NAP-RELAY: a mesh publish goes to the local relay and is
flooded to Circle peers with a hop budget (`ttl`) the napplet may request and
the user caps (publish default 3, subscribe default 2 — today's `EVENT_TTL` and
`MAX_REQ_TTL`). A mesh subscribe pulls backlog from Circle peers up to `ttl`
hops and streams later matches live.

Deferred (separate change, with inbox/outbox): `relay.publish` currently floods
the mesh at ttl 3; it must become spec-conformant (no mesh) once `mesh` exists.

## Tasks

1. **Runtime crate — seam, handler, spec.** `MeshSink` seam (`limits`,
   `publish(event, ttl)`, `pull(filters, ttl)`), `nap/mesh.rs` (`info`,
   `publish`, `subscribe`/`close`), domain-scoped session subscriptions,
   `"mesh"` in `IMPLEMENTED_DOMAINS`, `deliveries_for` emits `mesh.event`,
   `MemMesh` in `testing.rs`, unit tests. Spec at
   `docs/design/napplet/NAP-MESH.md`.
   - verify: `cargo test -p myco-napplet-runtime`
2. **Runtime crate — prelude supplement.** `assets/myco-prelude.js` installs
   `napplet.shell.{supports,services}` (cached from `shell.init`) and
   `napplet.mesh` over the same flat envelope wire; `prelude::render` appends
   it after the vendored `install()`. Tests pin ordering and content.
   - verify: `cargo test -p myco-napplet-runtime`
3. **myco-core — caps, ttl-aware accept, sink impl.** Settings
   `napplet_mesh_publish_ttl` / `napplet_mesh_subscribe_ttl`; action
   `SetNappletMeshReach`; state fields; `RelayHub::accept_local_with_ttl`
   (gossip honours an explicit local ttl); `NappletMeshSink` over hub +
   `Content::pull_from_peers`; wired into `NappletHost`.
   - verify: `cargo test -p myco-core`, `cargo clippy --all-targets -- -D warnings`
4. **Android.** `AppState` fields + action, Settings "Mesh reach for apps"
   steppers, `capabilityWording("mesh")`.
   - verify: Kotlin compiles (`./gradlew assembleDebug` needs the NDK build;
     if not run, say so)
5. **Docs.** `event-gossip.md` §2.6/knobs, `napplet-runtime.md` S5 + §7.4,
   `CHANGELOG.md` [Unreleased], `README.md` settings mention.
