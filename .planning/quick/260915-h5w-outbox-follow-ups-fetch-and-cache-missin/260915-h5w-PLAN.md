# Outbox follow-ups

## Tasks

1. **Fetch and cache NIP-65 lists.** `OutboxService` looks up an author's
   kind 10002 in the local store; when absent, it asks the relay pool
   (internet defaults unless offline-only, plus Circle mesh relays) with a
   short bound, stores what it finds (the local relay is the cache), and
   remembers a miss for a while so a napplet naming an unknown author does
   not re-fetch on every call. A stored list older than a day is used now
   (`source: cache`) and refreshed in the background.
   - verify: `cargo test -p myco-core outbox`
2. **NAP-RELAY reads through the pool.** `relay.query` queries the policy
   plan's lanes (local + configured relays) bounded and deduped;
   `relay.subscribe` answers the local backlog, then pulls the pool — or
   `options.relay` alone, validated — into the local relay for live delivery.
   - verify: `cargo test -p myco-napplet-runtime`
3. Docs: design doc S2/S3 lines, CHANGELOG.

NIP-66 relay intelligence: out of scope (a MAY; needs internet monitors,
which the offline case never has).
